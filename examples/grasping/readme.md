# 🚀 Quick Start
### 1. Train the model
```bash
python examples/grasping/motion_planning_grasp_train.py --num_envs 4096 --max_iterations 500
```
### 2. Evaluate the trained model
```bash
python examples/grasping/motion_planning_grasp_eval.py
```

### 3. Check logs
```bash
ls logs/motion_planning_grasp/
```
